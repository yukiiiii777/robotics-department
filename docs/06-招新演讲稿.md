# 机器人部门招新演讲稿（2-3分钟 · 约800字）

---

大家好！

我是人工智能实验室机器人部门的成员。今天用两分钟，带大家认识一下我们部门——一个能让你**亲手摸到真机器人**的地方。

## 一、我们是谁

先问大家一个问题：你觉得人工智能只存在于电脑屏幕里吗？

在我们部门，不是。我们研究的叫「具身智能」——简单说，就是**给人工智能装上身体**，让它能看得见、摸得着、动得了。电影里那种能帮你拿快递、收拾桌子的机器人，就是我们在做的事情。

## 二、我们有什么

说到动手，就得亮一亮我们的家底了。

第一件，**OpenFlex Ultra 轮式双臂机器人**。它有一米七高，两只机械臂能各拎起5公斤的东西，下面是四个轮子的底盘，可以一边走一边干活。我们给它装了一块 RTX 4090 显卡——很多同学打游戏都未必用得上的顶配显卡，在我们这儿是用来给机器人「长脑子」的。

第二件，**松灵 PiPER 机械臂**。它就像机器人的「手臂练习台」，你写几行 Python 代码，就能指挥它抓东西、写字、画画。

第三件，**PICO VR 眼镜**。戴上它，你一抬手，机器人的手臂就跟着动——你做一遍，机器人就学会一遍。你玩游戏是娱乐，我们玩游戏是在给机器人采集训练数据。

## 三、我们学什么

部门有三个方向，大家可以按兴趣选：

- 想练「**手**」的，学**机械臂**：怎么让机器人的手臂又稳又准地抓取东西；
- 想写「**大脑**」的，学 **VLA**：这是现在最火的方向，让机器人看图听指令就能自己行动；
- 想当「**司机**」的，学**底盘导航**：让机器人自己认路、自己避开障碍。

不管选哪个，Linux、ROS、Python 这些基本功，部门都会带你从零学起。**零基础完全不用担心**，大家都是这么过来的。

## 四、你能得到什么

在部门里，你的成长路径很清晰：先在电脑仿真里练手，再上真机做任务，然后参与真实项目——从教机器人动作，到训练模型，最后看着它在真机上跑起来。

到那时候，你简历上写的就不只是「学过什么课」，而是「**我训练过一个真的会干活的机器人**」。这句话，保研、找实习、打比赛，都硬气。

## 五、结尾

最后说一句：很多同学觉得机器人离自己很远，其实它离你只差一个选择。

想写大脑、想练手臂、想当司机的，机器人部门，等你上手。

谢谢大家！

## 📝 演讲小提示（不用念）

- **节奏参考**：全文约 800 字，正常语速刚好 2.5~3 分钟；如果超时，可砍「三、我们学什么」里的方向介绍细节。
- **重音位置**：加粗部分建议放慢、加重；「我训练过一个真的会干活的机器人」这句是全场钩子，务必停顿一下再讲。
- **互动技巧**：开头「AI 只在屏幕里吗」可以停两秒扫一眼观众；介绍设备时如果有实物或海报，指一下对应位置效果更好。
