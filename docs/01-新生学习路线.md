# 01 · 新生学习路线

> 从零基础到「我训练过一个真的会干活的机器人」，四步走。每一步都有真机等你上手。

## 路线总览

```
仿真入门 ──► 真机任务 ──► 示教数采 ──► 训练模型 ──► 真机部署
 (1-2月)     (1-2月)      (持续)       (持续)       (闭环)
```

## 第 0 步：环境准备（第 1 周）

- [ ] 安装 Ubuntu 22.04（双系统或虚拟机均可，推荐双系统）
- [ ] 安装 ROS 2 Humble（官方一键脚本），跑通官方 Demo 小乌龟
- [ ] 掌握 Linux 基础命令 + Git 基本操作（clone / commit / push）
- [ ] Python 基础：能写函数、类，会用 numpy

**检验标准**：`ros2 topic list` 会用，能看懂一个 launch 文件在干什么。

## 第 1 步：仿真入门（1-2 个月）

**目标**：在电脑里跑通第一个虚拟机器人。

- [ ] ROS 2 核心概念：topic / service / action / launch / URDF
- [ ] 学会用 RViz 可视化、用 Gazebo 或 Isaac Sim 做仿真
- [ ] 了解 OpenFlex 的开源仓库结构（[GitHub](https://github.com/OpenFleX-Wheeled-Humanoid/OpenFleX)）， clone 下来读 README
- [ ] 在 MuJoCo 里打开 OpenFlex 模型（官方 `openflex_mujoco` 仓库），拖动滑块控制关节

**检验标准**：能解释 OpenFlex 仓库里 `openflex_ws/src` 各子包（chassis / lift / arm / head / vr_bridge）分别管什么。

## 第 2 步：真机任务（1-2 个月）

**目标**：在真机上完成第一个任务。按方向三选一深入：

### 🦾 机械臂方向
- [ ] 正逆运动学（会推公式 + 会调库）
- [ ] MoveIt 2：给 PiPER 或 OpenFlex 双臂写一个抓取 demo
- [ ] 理解 `ros2_control` 架构（OpenFlex 全身关节都归它管，100Hz）

### 🚗 底盘导航方向
- [ ] 用 MID360 + FAST-LIO2 建一张图（`mapping.launch.py`）
- [ ] 3D 地图转 2D 栅格地图（`pcd_to_nav2_map`）
- [ ] Nav2 跑通 `full_system.launch.py`，RViz 里点 Nav2 Goal 让机器人自己走到目标
- [ ] 读懂 NMPC 局部控制器是什么、和普通差速控制有何不同

### 🧠 VLA 方向
- [ ] 先读 [VLA 入门讲义](02-VLA入门讲义.md)
- [ ] 戴 PICO 眼镜做一次 VR 全身遥操（`wholebody_vr_teleop.launch.py`）
- [ ] 跟着[数采手册精要](04-OpenFlex-PI0.5数采训练推理手册精要.md)录一小批 episode 数据
- [ ] 用 LeRobot Studio 检查数据质量（剔模糊 / 偏视 / 过快）

**检验标准**：真机上有一个自己亲手跑通的任务，并能讲清楚每一步的指令含义。

## 第 3 步：数据闭环（部门核心工作）

**目标**：走完「示教 → 训练 → 部署」一整圈。

- [ ] 规范化录制 30+ episodes（参考手册第 5 节的录制规范：慢速平稳、起始姿态统一）
- [ ] 本地用 ACT 模型训练第一次（RTX 4090 就够；Pi0.5 官方要求 A100 40G，可云端租卡）
- [ ] 把训练好的策略部署回真机做离线推理（`HF_HUB_OFFLINE=1`）
- [ ] 失败案例重新采集数据 → 再训 → 再部署，转起数据飞轮

**检验标准**：有一份自己的数据集 + 一个能真机跑起来的 checkpoint。

## 第 4 步：输出与竞赛

- [ ] 把数据闭环沉淀成技术报告 / 论文素材
- [ ] 对接软件杯、挑战杯等竞赛课题
- [ ] 高年级带新成员，把经验写回本仓库（docs 目录欢迎 PR）
