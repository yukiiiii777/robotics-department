# 00 · 部门介绍

> **一句话定位**：以真实机器人为载体，围绕「移动操作 + 具身智能数据闭环」，培养从底盘导航、机械臂控制到 VLA 模型的全栈机器人开发能力。

## 一、部门简介

机器人部门是人工智能学院人工智能实验室的核心实践部门。我们相信**具身智能不能只停留在论文和仿真里**——部门以轮式双臂机器人、六轴机械臂和 VR 遥操作设备为硬件底座，让每位成员在真实机器人上完成「感知 → 决策 → 执行」的完整闭环开发。

部门的学习主线覆盖当前机器人领域最热门的三个方向：

- 🦾 **机械臂操作**：运动学、轨迹规划、抓取与操作
- 🧠 **VLA（Vision-Language-Action）**：视觉-语言-动作大模型，具身智能的「大脑」
- 🚗 **底盘导航**：SLAM 建图、自主定位与路径规划

同时打牢 **ROS 2、编程、仿真** 等机器人开发的通用地基。

## 二、硬件设施

### 2.1 OpenFlex Ultra 轮式双臂机器人（成都长数科技有限公司）

部门主力设备。成都长数科技出品的开源生态整机平台，集移动底盘、升降、双臂、多视角视觉与高算力于一体，原生支持 **VR 遥操 → 数据采集 → VLA 训练 → 真机推理** 的完整闭环。四个亮点：

- 🤖 **全身 27 自由度**——双臂 + 升降 + 四轮四转全向底盘，能「边走边干」的移动操作平台
- 👁️ **多视角视觉**——头部 / 双腕 / 底盘四路 RGB-D 相机 + MID360 激光雷达，感知与建图够用
- 💪 **自配技嘉 RTX 4090（24 GB）**——真机旁就能本地训练和推理 VLA 模型
- 🧠 **开箱即用的数据闭环**——预装 VR 全身遥操、MoveIt 2、Nav2 与 Lerobot VLA 工作流，支持 Pi0.5 等模型直接部署

**能干什么**：双臂协同抓取、移动操作、VR 遥操示教数采、VLA 真机部署验证、SLAM 建图与自主导航。

### 2.2 PiPER 轻量六轴机械臂（松灵科技）

- 6 自由度：1.5 kg 负载、626 mm 工作半径、±0.1 mm 重复定位精度
- 支持 ROS 2 / Python SDK / 拖动示教，是练手机械臂开发的最佳入门平台
- 配合 LeRobot 工作流做 VLA 数据采集与算法真机验证

### 2.3 PICO 4 Ultra VR 一体机

- 戴上眼镜第一视角示教机械臂，你的操作就是训练数据

## 三、学习方向与技术路线

| 方向 | 学什么 | 用什么设备 |
| --- | --- | --- |
| 🦾 **机械臂开发** | 正逆运动学、轨迹规划、MoveIt 2、双臂协同、抓取策略 | OpenFlex Ultra 双臂 / PiPER |
| 🧠 **VLA 具身智能** | VR 遥操示教、多视角数据集构建、LeRobot 工作流、Pi0.5 / ACT 等模型训练与真机推理 | OpenFlex Ultra + PICO 4 Ultra |
| 🚗 **底盘导航** | 激光 SLAM 建图（MID360）、自主定位、Nav2 路径规划、全向底盘运动控制 | OpenFlex Ultra 底盘 |
| 🧰 **通用基础** | Linux + ROS 2 (Humble)、Python / C++、MuJoCo / Isaac Sim 仿真、Git 版本管理 | 全体成员必修 |

三条主线不是割裂的——一台 OpenFlex Ultra 上同时需要「腿」（导航）、「手」（机械臂）和「脑」（VLA），部门成员按兴趣分方向深入，按项目组队协作。
